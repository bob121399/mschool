# Демо по ссылке в интернете

Отдельное **демо-окружение** с синтетическими данными: сайт и фоновый worker на Render (регион Франкфурт),
база, вход и файлы — в отдельном проекте Supabase (eu-central-1). С production оно не связано. Скрипт
откажется работать с проектом Supabase, в названии которого нет `demo`, и не станет наполнять проект, где уже есть компании.

## Что сделать вам (≈ 15 минут, один раз)

1. **Supabase** — https://supabase.com: зарегистрируйтесь и создайте организацию (бесплатный план подходит).
   Проект создавать не нужно, скрипт создаст `mschool-demo` сам. Затем откройте Account → Access Tokens и
   создайте токен.
2. **Render** — https://render.com: зарегистрируйтесь через GitHub и дайте Render доступ к репозиторию
   `bob121399/mschool`. Затем New → Blueprint → репозиторий `bob121399/mschool`, ветка `mvp-iteration-02`.
   Render прочитает `render.yaml` и спросит значения переменных: оставьте их пустыми, а если поле обязательно, впишите `-`. Скрипт заменит их сам.
   Первая сборка упадёт без этих значений — это нормально. Затем Account Settings → API Keys → создайте ключ.
3. **Передайте доступы в окружение Claude, не в чат:** меню облачного окружения в заголовке сессии → Edit →
   секреты/переменные окружения:

   | Переменная | Значение |
   |---|---|
   | `SUPABASE_ACCESS_TOKEN` | токен Supabase из шага 1 |
   | `SUPABASE_DB_PASSWORD` | придумайте надёжный пароль для базы демо (≥ 16 символов) |
   | `RENDER_API_KEY` | ключ Render из шага 2 |
   | `OPENAI_API_KEY` + `OPENAI_TUTOR_MODEL`, `OPENAI_ASSESSOR_MODEL`, `OPENAI_WORKER_MODEL` | по желанию, для живого ИИ |

   Если у вас несколько организаций Supabase, добавьте `SUPABASE_ORG_SLUG`.
4. Откройте **новую** сессию (секреты подхватываются при старте) и напишите: «разверни демо по docs/demo-hosting.md».

## Что сделает скрипт (`npm run demo:hosted`)

1. Найдёт или создаст проект Supabase `mschool-demo` и дождётся его готовности.
2. Применит миграции 0001–0007 (`supabase db push`).
3. Настроит вход: адрес сайта, разрешённые redirect-адреса, MFA (TOTP) и русские шаблоны писем. **Самостоятельная
   регистрация закрыта:** по публичной ссылке посторонние не смогут создавать компании.
4. Заполнит базу синтетическими данными: 2 компании, 24 сотрудника, курсы, счета и метрики. Если ИИ настроен,
   эмбеддинги источников считаются настоящей моделью, иначе тьютор не найдёт источники.
5. Пропишет переменные в сервисах Render и запустит сборку сайта и worker.
6. Сохранит карточку доступа в `.secrets/hosted-demo-access.txt` (вне git): адрес, логины, пароль и TOTP-секрет
   суперадмина для Google Authenticator.

## Стоимость и ограничения

| Что | Стоимость | Комментарий |
|---|---|---|
| Supabase Free | $0 | Проект засыпает после 7 дней без активности: нажмите «Restore» в панели |
| Render web `0.5c-512mb` | ≈ $7/мес | На бесплатном плане сайт засыпает и первая загрузка идёт ~1 минуту: для показа не годится |
| Render worker `0.5c-512mb` | ≈ $7/мес | Можно удалить после показа: без него не строятся еженедельные отчёты |
| OpenAI | центы за показ | Только если добавлен ключ |

- Письма: встроенная почта Supabase доставляет только адресам участников вашей организации Supabase. Поэтому
  приглашения на вымышленные адреса в демо **не отправляются**, а реальные приглашения не уходят случайно.
- Загрузка новых PDF: без антивируса (BLK-02) документ останавливается на «сканер недоступен». Для демо используйте
  уже загруженные источники.
- Пароль демо-аккаунтов общий. Не публикуйте ссылку вместе с паролем открыто: передавайте их отдельно.
- Удалить демо: удалите сервисы на Render и проект `mschool-demo` в Supabase.
