# Демо по ссылке в интернете

Отдельное **демо-окружение** с синтетическими данными: сайт на Vercel (функции во Франкфурте, `fra1`), база,
вход и файлы — в отдельном проекте Supabase (eu-central-1). С production оно не связано. Скрипт откажется работать
с проектом Supabase, в названии которого нет `demo`, и не станет наполнять проект, где уже есть компании.

## Что сделать вам (≈ 10 минут, один раз)

1. **Supabase** — https://supabase.com: зарегистрируйтесь и создайте организацию (бесплатный план подходит).
   Проект создавать не нужно, скрипт создаст `mschool-demo` сам. Затем откройте Account → Access Tokens и
   создайте токен.
2. **Vercel** — https://vercel.com: зарегистрируйтесь. Затем Account Settings → Tokens → создайте токен
   (scope — ваша команда). Подключать GitHub не обязательно: скрипт загружает код сам.
3. **Передайте доступы в окружение Claude, не в чат:** меню облачного окружения в заголовке сессии → Edit →
   секреты/переменные окружения:

   | Переменная | Значение |
   |---|---|
   | `SUPABASE_ACCESS_TOKEN` | токен Supabase из шага 1 |
   | `SUPABASE_DB_PASSWORD` | придумайте надёжный пароль для базы демо (≥ 16 символов) |
   | `VERCEL_TOKEN` | токен Vercel из шага 2 |
   | `OPENAI_API_KEY` + `OPENAI_TUTOR_MODEL`, `OPENAI_ASSESSOR_MODEL`, `OPENAI_WORKER_MODEL` | по желанию, для живого ИИ |

   Если у вас несколько организаций Supabase или команд Vercel, добавьте `SUPABASE_ORG_SLUG` / `VERCEL_TEAM_ID`.
4. Откройте **новую** сессию (секреты подхватываются при старте) и напишите: «разверни демо по docs/demo-hosting.md».

## Что сделает скрипт (`npm run demo:hosted`)

1. Найдёт или создаст проект Supabase `mschool-demo` и дождётся его готовности.
2. Применит миграции 0001–0007 (`supabase db push`).
3. Заполнит базу синтетическими данными: 2 компании, 24 сотрудника, курсы, счета и метрики. Если ИИ настроен,
   эмбеддинги источников считаются настоящей моделью, иначе тьютор не найдёт источники.
4. Создаст проект Vercel `mschool-demo`, пропишет переменные окружения и опубликует сайт. Загружается только код:
   `.vercelignore` исключает `.secrets`, `.env*` и результаты сборки и тестов.
5. Настроит вход в Supabase: адрес сайта, разрешённые redirect-адреса, MFA (TOTP) и русские шаблоны писем.
   **Самостоятельная регистрация закрыта:** по публичной ссылке посторонние не смогут создавать компании.
6. Проверит `/api/health` и сохранит карточку доступа в `.secrets/hosted-demo-access.txt` (вне git): адрес, логины,
   пароль и TOTP-секрет суперадмина для Google Authenticator.

## Стоимость и ограничения

| Что | Стоимость | Комментарий |
|---|---|---|
| Supabase Free | $0 | Проект засыпает после 7 дней без активности: нажмите «Restore» в панели |
| Vercel Hobby / Pro | $0 / $20 в мес. | По условиям Vercel план Hobby — только для некоммерческого использования; для показа инвестору честнее Pro |
| OpenAI | центы за показ | Только если добавлен ключ |

- **Фоновый worker не размещается** (Vercel не держит постоянные процессы). Работают все экраны, готовые данные,
  метрики и живой ИИ (тьютор и проверка). В очереди остаются только фоновые задачи: обработка новых PDF, новые
  еженедельные отчёты, ответы агентов поддержки и sales. При необходимости worker можно запустить с любого
  компьютера: `npm run worker:start` с переменными демо-проекта.
- Письма: встроенная почта Supabase доставляет только адресам участников вашей организации Supabase. Поэтому
  приглашения на вымышленные адреса в демо **не отправляются**, а реальные приглашения не уходят случайно.
- Загрузка новых PDF: без worker и антивируса (BLK-02) документ не обрабатывается. Для демо используйте уже
  загруженные источники.
- Пароль демо-аккаунтов общий. Не публикуйте ссылку вместе с паролем открыто: передавайте их отдельно.
- Удалить демо: удалите проект `mschool-demo` в Vercel и в Supabase.
