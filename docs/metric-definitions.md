# Словарь метрик

## Платформа (superadmin, `lib/billing/platform.ts`, `lib/billing/metrics.ts`)

| Метрика | Определение | Знаменатель / примечание |
|---|---|---|
| MRR | Сумма `amount_minor` счетов закрытого месяца со статусом issued/paid, нормализованных на месяц; одна валюта | Demo, void, draft, one-off исключены; валюты не суммируются |
| ARR | 12 × MRR (run-rate) | Не фактическая годовая выручка |
| Платящие компании | Компании с регулярным счетом в месяце | — |
| Активные места | Сумма `active_seats` счетов месяца | Место = уникальный не-superadmin, не сервисный пользователь с серверным событием (`lesson_engaged` ≥30 с по одноразовому токену, `assessment_submitted`, `tutor_question`) в месяце по `billing_timezone` |
| NRR | (MRR конца по компаниям начала) / MRR начала | Новые компании исключены; N/A при нулевом знаменателе |
| GRR | Σ min(начало, конец) / MRR начала | — |
| AI COGS | Σ(tokens × датированная ставка) / 1e6 + OCR | Неизвестная ставка → N/A, не 0 |

## HR (`public.hr_report_metrics`, период — неделя Пн 00:00 → Пн 00:00 в timezone tenant)

| Метрика | Определение |
|---|---|
| assigned | Назначения, созданные в периоде |
| active_learners | Сотрудники с серверным событием в периоде |
| started | Назначения с хотя бы одним событием после назначения (до конца периода) |
| completed | Назначения, завершенные в периоде |
| overdue | Не отмененные назначения со сроком до конца периода, не завершенные к сроку |
| median_hours_to_completion | Медиана часов от назначения до завершения (завершенные в периоде) |
| first_attempt_pass_rate | Доля пройденных среди первых **успешно проверенных** попыток по уроку в периоде (технические ошибки исключены) |
| appeals | Апелляции периода / проверенные попытки периода |
| ai_errors | Попытки с технической ошибкой провайдера |
| departments | locked / in_progress / completed прогресса активных назначений; группы <5 скрыты |
